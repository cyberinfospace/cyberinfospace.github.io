# AGENTS.md

Standard Cyber Info Space repository rules for AI assistants and human contributors:

1. Never commit secrets, `.env` files, API keys, or private credentials.
2. Never include private repository names, internal URLs, or internal project details in this public repository.
3. Follow Conventional Commits (`feat:`, `fix:`, `ops:`, `docs:`, `sec:`, `chore:`).
4. Pin GitHub Actions to verified full commit SHAs with least-privilege `permissions:`.
